# 米提亚的围巾 · 手部动捕重定向

网页里有一条从官方 PMX 切出来的围巾（末端分叉成 4 根须子），用摄像头的手部动捕实时驱动。
所有推理在本地跑，画面不出机器。

## 🎮 在线体验

**https://mitiya.pages.dev/** — 打开就能玩，不用安装

- 需要摄像头（浏览器会请求权限），手机也能用
- 首次加载要下载约 25 MB 模型，进度条走完即可
- 想跟它猜拳：点右下角「切到猜拳」
- 英文界面：右下角 `EN` 按钮，或访问 `?lang=en`

> Live demo: **https://mitiya.pages.dev/** — webcam required, runs entirely in your browser.

## 跑起来

npm install

## 骨骼结构

模型共有 982 根骨骼，围巾只用到其中 20 根：

- **主干 8 节**（总长 12.05）：`Bone_ShawlE01_L` → `Bone_RibbonSplineIK01~06_L` → `Bone_HandA01_L`
- **四根须子各 3 节**：`Bone_FingerA01~03_L`（挂 SplineIK06）、`Bone_FingerB/C/D01~03_(L|R)`（挂 HandA01）

权重来自官方蒙皮，未做任何重绑；切网格只删三角形。

## 姿态还原怎么做的

1. **识别**：MediaPipe `HandLandmarker`（GPU，失败回落 CPU），同时取 `landmarks`（屏幕）和 `worldLandmarks`（真实三维，米）
2. **判据全用三维**：手指伸直 = 近节/中节夹角阈值；捏合 = 拇指尖↔食指尖三维距离 ÷ 掌宽；剪刀额外要求食指中指张开
3. **手掌基座**：`腕→中指根` 为 U，`小指根→食指根` 为 S，N = U×S，建立 `(S,U,N)` 正交基
4. **重定向**：把模型手掌基座映射到 `HandA01` 局部轴（常量矩阵 `modelBasis`），每根须子的每段只映射**相对“伸直”的偏转**，保留模型自身的张角
5. **约束**：单关节上限（默认 1.9 rad）、死区（0.18 rad，静止不抖）、扭转跟随（绕段轴把带宽方向拉回手掌法线）、逐帧四元数平滑

## 围巾主体

- 两端固定：根部钉在画面下方，末端 IK 钉在手上（`?marker=1` 可看目标点）
- 中间按**弧长约束的抛物线垂度**求解（二分求垂度使弧线长度正好等于围巾长度），所以是自然下垂而不是被拉直

## 猜拳

不需要按钮，也不需要倒计时：**你做出手势，围巾当场识别并回应**。

- 玩家出拳：握拳 = 石头，食指+中指分开 = 剪刀，五指张开 = 布
- 手势需稳定 0.16 s 才触发（防抖）
- 围巾"想一下"（0.24 s）后出自己的手型。**这三种姿态不是手写参数，而是回放用户提供的三张照片里的手部动捕**：
  石头 ← 握拳照片、剪刀 ← 剪刀照片、布 ← 张开照片。录制脚本 `tools/dump-poses.mjs` 把 MediaPipe worldLandmarks
  算出的"5 指 × 3 段方向"写进 `src/game/poses.ts`，运行时再重定向到须子骨骼上。
- 猜拳时围巾**只跟随手的位置**，手型完全由回放姿态决定；姿态之间用 slerp 平滑过渡（时间常数约 0.45 s）
- 判定按标准规则（石头赢剪刀、剪刀赢布、布赢石头），比分持续累计，右下角「重置比分」清零
- `?counter=1` 让围巾每次出克制你的手型；`?scarf=rock|scissors|paper` 固定它的出拳（调试用）
